# Terapia de Apoio

Sistema de agendamento para uma clínica de fisioterapia, desenvolvido como projeto acadêmico e de portfólio.

## Objetivo

Permitir o gerenciamento de pacientes, profissionais, serviços e agendamentos, com validação de disponibilidade dos profissionais.

## Tecnologias

- **Backend:** C# e ASP.NET Core Web API
- **Banco de dados:** PostgreSQL
- **Persistência:** Entity Framework Core e Npgsql
- **Frontend:** HTML, CSS e JavaScript

## Arquitetura

O projeto utiliza uma arquitetura em camadas, com separação entre API, aplicação, domínio e infraestrutura.

A proposta é aplicar os princípios SOLID e utilizar Design Patterns quando fizerem sentido para as responsabilidades do sistema.

## Funcionalidades previstas

- Cadastro e consulta de pacientes
- Cadastro de profissionais e serviços
- Gerenciamento da disponibilidade dos profissionais
- Criação, consulta e cancelamento de agendamentos
- Prevenção de conflitos de horários
